# Título do problema

| | |
|---|---|
| **Categoria** | Rede / Sistema / Aplicativo / Impressão |
| **Nível de atendimento** | N1 / N2 |
| **Testado** | Sim / Parcial / Não (explicar o que foi e o que não foi testado) |
| **Altera o sistema?** | Diagnóstico: não (somente leitura). Solução: sim, ver passos marcados |

## Sintoma

O que o usuário relata, nas palavras dele. Como o problema aparece no relatório do kit, se aparecer.

## Como confirmar (diagnóstico)

Comandos somente leitura, na ordem em que devem ser executados, e como interpretar o resultado de cada um.

## Causas prováveis

Da mais comum para a menos comum.

## Solução

Passos numerados. Passos que alteram o sistema ou exigem PowerShell como Administrador levam a marca **(Administrador)**. Registrar o valor original antes de qualquer alteração de configuração.

## Quando escalar

Critérios objetivos para passar o chamado para N2, infraestrutura ou fornecedor.

## O que registrar no chamado

Informações que a próxima pessoa vai precisar para continuar sem repetir o diagnóstico.

## Exemplo real

Um caso que aconteceu de verdade, com data, evidência e desfecho (sem dados pessoais).
